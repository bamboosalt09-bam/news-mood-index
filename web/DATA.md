# 웹 서비스 자료 약속 (2026-10-31)

해커톤(AI-SW 개발 해커톤, 마감 2026-11-05 18:00) 산출물: **오늘의 뉴스 시장 분위기 + AI 해설**.
이 컴퓨터에서 `python web/build.py`가 자료를 만들어 `web/public/data/`에 JSON으로 쓰고, 정적 화면(`web/public/`)이 그것만 읽는다. 서버·API 키는 웹에 없다. 배포는 Firebase Hosting (`web/firebase.json`, public = `web/public`).

## 파일

- `web/public/data/latest.json` — 화면이 읽는 유일한 파일 (아래 형식)
- `web/public/data/archive/<YYYY-MM-DD>.json` — 같은 형식, 날마다 하나 (지난 해설 보기용)
- `web/public/data/sample.json` — 화면 개발용 가짜 자료 (같은 형식)

## latest.json 형식

```json
{
  "updated": "2026-10-31T12:00:00+09:00",
  "markets": {
    "ko": { ...시장 },
    "en": { ...시장 }
  }
}
```

## 지켜야 할 것

- 예측·매수/매도 표현 금지. 해설은 "보도된 내용" 요약이고 인과를 단정하지 않는다 ("금리 동결에도 급락" ≠ 금리 동결이 원인).
- 제목은 묶음 대표 몇 개만, 원문 링크와 함께. 대량 재게시 금지.
- 수치 근거: 같은 날 상관 한국어 +0.65·영어 +0.40, 다음 날 예측력 없음, 표본외 변동성 예측 불통과 (docs/실험기록.md 2026-10-31).
