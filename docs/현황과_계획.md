### M2 구조

- 입력은 clean한 제목 하나, 세 갈래를 더해 tanh(64) → 7단계 확률 → 기대값 = 점수다.
  - ① 글자 1~3조각 해시 1.6만 칸 → 64
  - ② 사전 특징 20 → 64
  - ③ kiwipiepy 형태소(형태/품사, 최대 40)마다 16×16 행렬 `I + A[형태소]`를 시작 상태 v0에 읽는 순서대로 곱함 (상태 크기 4 상한) → 64
- 뒤처리: 안전장치(사전 규칙과 엇갈리면 중립), 전망·의견 절반, 수준만 말한 제목 0. 화면 경계 +0.9 / −0.85.
- 매개변수 615만 (형태소 1만 9,935개 × 256이 510만). 사전 낱말과 같은 형태소 87개는 출발점을 줌(방향 = 감성 칸에 더함, 부정 = 뒤집기, 지난 상태 = ×0.2).
- 학습 때 사전·형태소 목록은 모델 파일 안에 저장돼 있어 `lexicon.tsv`를 바꿔도 이 모델 입력은 그대로다.
- 만드는 법: `python 실험/seqexp.py cmsm d morph lexinit seqlr=0.001` → `python 실험/cmsm_to_numpy.py models/seq_cmsm_d_morph_lexinit_seqlr=0.001.pt ko_cmsm_m2-감성`. 지금 seqexp는 큰 시험지와 거의 같은 제목까지 빼서 74,196개로 학습한다. 큰 시험지 채점은 `python 실험/bigtest.py`.

## 4. 알게 된 것

- **본문은 0 비율이 병목이었다.** 본문 라벨 85%가 0이라 모델이 0으로 뭉갰다. 라벨 양(4.6배)·형태소 상한(40→128)은 거의 효과 없고, 0을 줄인 것이 효과의 거의 전부. 다음 라벨링은 작은 모델로 0 아닐 것 같은 문장을 골라 붙이면 싸다 (무작위 몫은 꼭 남길 것).
- **강점은 작고 빠르고 기준에 맞는 것.** 1억 매개변수급 모델보다 우리 기준·최근 제목에서 정확하고, 방향을 덜 틀리고, CPU에서 100배 빠르다. 넓은 기준(평범한 소식도 긍정)에서는 놓침이 많다.
- **다음 날 예측력은 없다.** v1·KR-FinBert 지수 모두 오늘 효과를 빼면 다음 날 등락과 상관 0 근처.
- **과거 기간에서 약하다.** 과거 시험지(`ko_과거시험1500`)의 0 아닌 제목에서 7단계 44%·부호 84% (8~10월은 60%·89%). 과거 Opus 라벨 6천 개로 라벨만 바꿔서는 안 풀린다.

- **사전은 더 넓혀도 거의 안 바뀐다.** 낱말 하나짜리 말은 글자 조각·형태소 갈래가 이미 배웠다. 새 시험지 1,500개에서 사전 판 셋의 맞음·헛경보·방향 틀림이 완전히 같았다.

- **측정이 병목이었다.** 700개로는 7단계 2%p를 못 가린다. 큰 시험지(1,498)에서 처음 효과가 또렷해졌다. 효과 몫: Haiku 정답 약 +4%p, 순서 갈래 약 +1%p.
- **정답 품질이 천장이다.** 선생 정답에 묶이면 구조를 바꿔도 7단계가 안 오른다.
- **화면 판정(호재·악재·중립)은 83% 근처 천장**이고, 개선은 주로 세기(7단계)에서 나온다.
- **사전이 작은 모델을 끌고 간다.** 사전이 틀리면 모델도 틀린다.
- **비용**: 가벼운 Haiku 1만 개 ≈ 90묶음, 묶음당 출력 약 3만 토큰. 답 빠짐 약 5% → 개수 강제로 해결.
- **시험지 설계 실수 두 번**: 순서 짝은 사전으로 풀렸고, 큰 시험지는 Opus·사람 라벨과 겹쳤다. 새 시험지는 학습 라벨 전부와의 겹침을 먼저 확인한다.

## 8. 상업화 점검 (2026-10-31, 해커톤 뒤 순위)

막는 것 (광고를 붙이기 전에 풀어야 함):
- **제목 출처 권리.** 지금 수집의 큰 몫인 Google News RSS는 개인·비상업 이용 조건으로 알려져 있고, 언론사 RSS(연합·한경·CNBC·MarketWatch·BBC·NYT)도 약관이 제각각이다. 광고를 붙이면 상업 이용이 된다.
  → 언론사별 RSS 약관 확인, 화면에는 묶음 대표 제목 몇 개 + 원문 링크만(지금처럼), 필요하면 정식 자료(빅카인즈 등) 검토.
- **시세 출처.** 네이버 차트 자료를 받아 쓰는 중. 공개 서비스에서는 이용 조건이 분명한 출처(공공데이터포털 금융위원회 지수시세 등)로 바꾸거나, 종가 대신 등락률만 보여 주는 쪽을 검토. S&P 500 값은 지수 사업자 라이선스 문제를 따로 확인.
- **도메인.** AdSense는 소유한 최상위 도메인을 요구하는 쪽으로 바뀌어 `*.web.app`으로는 승인이 어려워 보인다 → 도메인 하나 (연 1~2만 원).
- **법.** 광고 수익만 있는 무료 공개 사이트는 유사투자자문업 신고 대상이 아니라는 금감원 설명이 보도됨. 유료 회원·리포트 판매로 가면 신고 대상. 매수/매도·예측 표현 금지는 그대로.

있어야 하는 것:
- 매일 자동 갱신 (수집 → 판정 → build → 배포). 지금은 이 컴퓨터가 켜져 있어야 함. 실패하면 화면에 "자료 지연" 표시.
- 개인정보처리방침에 광고 쿠키 내용, about.html 연락처 채우기.
- 검색 유입용 날짜별 페이지 (archive를 날짜별 정적 페이지로) 와 공유 카드 이미지.
- AI 해설: Haiku로 하루 두 시장이면 비용은 하루 몇 원 수준. 키는 이 컴퓨터 환경 변수에만.

차별점 (`docs/실험기록.md` 같은 날 '기존 지수 견주기'): 한은 NSI·CNN 공포탐욕·VIX와 일부만 겹치고(상관 0.2~0.5), 그것들을 빼도 같은 날 시장과 맞는 뉴스 몫이 남는다 (한국어 +0.61, 영어 +0.23~0.26). 한국 시장의 같은 날 분위기 + 이유(기사 묶음)가 핵심이고, 예측은 팔 수 없다.
