# 학습 전 점검 절차 (필수)

긴 학습(미세 조정 35분 이상)을 돌리기 **전에** 아래를 순서대로 통과시킨다. 하나라도 실패하면 본 학습을 하지 않고 원인부터 고친다.
이 절차는 2026-10-26, 사전 특징을 모델이 거의 쓰지 않는 상태(판정층 신호의 5%)로 최종 학습을 돌려 버린 일을 계기로 만들었다.

## 0. 전제조건 확인

- [ ] `labeled/라벨기준.md`가 확정 상태이고, `python labeled/check_labels.py` 후보 0건
- [ ] 학습용(`labeled/ko_more7.tsv`)과 시험지(`labeled/시험/`)가 겹치지 않음
- [ ] 이번 학습에서 **무엇을 확인하려는지, 어떤 결과면 무엇을 고를지**를 학습 전에 적어 둠 (결과를 보고 기준을 바꾸지 않음)

## 1. 특징 계산 검산 (1분)

- [ ] `python judge.py check` 통과
- [ ] 기본 행동 문장에서 사전 칸 값이 의도대로인지 눈으로 확인
  - 예: "코스피 4% 급락서 강보합 마감", "코스피 8% 하락" vs "0.1% 하락", "환율 30원 오른" vs "3원 오른", "실업률 오르지 않아", "위기설 공식 부인"
  - 새로 넣은 규칙이 있으면, 그 규칙이 걸리는 문장을 여기에 하나 이상 추가

## 2. 특징 사용 확인 (5분 안팎)

- [ ] 작은 바탕 모델(roberta-small)로 **1에폭만** 짧게 학습
- [ ] 사전 특징을 0으로 지웠을 때 기본 행동 문장의 점수 변화가 충분한지 확인
  - 기준: 사전이 강하게 말하는 문장(규칙 ±1 이상)에서 평균 |점수 변화| ≥ 0.3
  - 판정층 첫 층 신호에서 사전 비중 ≥ 20%
- [ ] 기준 미달이면 → 구조를 먼저 고친다 (사전 길 강화, 문장 모델 입력 가리기 등). 본 학습 금지

## 3. 방향 확인 (1분)

- [ ] 짧게 학습한 모델이 기본 행동 시험(`evaluate.py`의 16개)에서, 사전 규칙이 분명한 문장의 방향을 사전과 같게 냄

## 4. 본 학습

- [ ] 1~3을 모두 통과한 뒤에만 실행
- [ ] 전원 연결, 다른 무거운 작업 동시 실행 금지 (CPU를 나눠 쓰면 2배 가까이 느려짐)

## 5. 채점과 결정

- [ ] `python evaluate.py <지금 모델> <새 모델>`: 무작위 700개(최종) 기준
- [ ] 0번에서 적어 둔 기준으로만 결정. 300개 이하 시험지로는 1~3%p 차이를 판단하지 않음
- [ ] 결과와 결정을 git에 기록

## 판단 기준 메모

- 오류 우선순위: 방향 틀림 > 헛경보 > 놓침
- 무작위 700개에서 맞음의 95% 범위는 ±3%p 안팎이다. 이보다 작은 차이는 같은 실력으로 본다
