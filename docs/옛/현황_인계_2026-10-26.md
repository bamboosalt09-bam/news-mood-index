## 1. 목적과 사용자 기준

- **하는 일:** 경제 뉴스 제목 한 줄을 받아 세 가지를 판정한다.
  - **감성:** −2 ~ +2 (7등급: −2, −1, −0.5, 0, +0.5, +1, +2). 한국 주식 투자자 관점의 호재·악재
  - **주제:** 21칸 (`topics.txt`)
  - **범위:** 국내 / 국제 / 무관. 주제에서 자동으로 정해짐
- **언어:** 한국어와 영어는 별도 모델이다. 지금은 한국어 위주로 개선 중이다.
- **사용처**
  - 판정 창: 제목 하나 또는 여러 개를 붙여 넣어 바로 판정 (`판정하기.bat` → `judge.py`)
  - 뉴스 지수: 하루치 제목을 모아 평균 내서 공포탐욕지수·코스피와 비교 (`index.py`)
- **사용자 오류 우선순위 (가장 중요):** 방향 틀림 > 헛경보 > 놓침
  - 호재를 악재로 보는 게 최악이고, 그다음이 근거 없이 호재·악재를 띄우는 것이다.
  - 애매하면 중립으로 뭉개는 건 괜찮다.
- **사용자가 원하는 방식**
  - 답변은 항상 한국어로 한다.
  - 학습 횟수와 시간을 최소로 줄이고 싶어 한다. 전제조건을 먼저 다 정한 뒤 한 번에 학습하는 쪽을 선호한다.
  - 결과를 보고 값을 세밀하게 다시 맞추는 것을 경계한다.
- **하드웨어:** 노트북 CPU 하나 (Intel Core Ultra 5 125H, 엔비디아 GPU 없음). ko-sroberta 미세 조정은 한 번에 35~50분 걸린다.

### 모델 구조 (미세 조정)

```
제목 → 전처리(번호·[속보]·(종합) 제거) → 바탕 문장 모델(ko-sroberta, 12층, 1억 1천만)
     → 조각 평균(768칸) + 사전 특징(옛 사전 19칸 / 새 사전 20칸) → 판정층(16) → 7등급 확률
     → 점수 = 등급 기대값 × 배율 → 안전장치(사전 규칙과 ±1 이상 반대면 0) → 경계로 호재/중립/악재 표시
```

- 손실: 교차엔트로피. |라벨| ≥ 1을 틀리면 2배 벌점.
- 학습: 문장 모델 학습률 2e-5, 판정층 1e-3, 묶음 32, 3에폭(검증 손실이 나빠지면 멈춤).
- 학습 후 보정: 온도, 점수 배율.

## 6. 라벨 기준 요약 (자세한 건 `labeled/라벨기준.md`)

- **±2:** 시장 전체 사건만 (지수 2% 이상·급등락, 금리 깜짝 변경, 전쟁·종전, 한국 대상 큰 관세 변화, 대기업 부도, 상징적인 선 돌파). 개별 기업·업종은 최대 ±1.
- **±0.5:** 숫자로 작은 움직임 (지수 0.5% 미만, 환율 10원 미만 등), 그리고 전망·의견·질문형은 한 단계 약하게.
- **개별 종목:** 그 종목 기준 (상한가 +1, 1% 미만 ±0.5).
- **엇갈린 제목:** 주인공 기준. 둘 다 결과면 증시 우선.
- **숫자 기준표:** 지수 0.5/2%, 환율 10/30원, 유가 1/5%, 국채 5/15bp, 가상자산 3/10%.
- **라벨 상태:** 2026-10-25~26에 기준을 확정했다. 자동 수정 164건, 하나씩 검토 360건을 반영했고 다시 점검하니 남은 후보는 0건이다.
- **분포:** −2: 371, −1: 1,314, −0.5: 160, 0: 2,582, +0.5: 179, +1: 1,274, +2: 179

## 7. 알려진 문제와 위험

1. **실제 흐름 헛경보가 높다.** v2 기준 6.3%. 개발 시험지(2.1%)는 어려운 제목 위주라 실제와 분포가 다르다.
2. **시험지 오염 이력**
   - 개발 시험지(562)는 경계·안전장치를 고르는 데 이미 썼다.
   - 깨끗한 건 **무작위300과 사용자의 진단 세트 70개**(사용자가 갖고 있고, 학습에 쓰지 않기로 함)뿐이다.
3. **라벨은 Claude 한 명이 붙였다.** 천장은 라벨 일관성(화면 기준 약 88%)이다.
4. **영어는 한국어 개선을 하나도 반영하지 않았다.** ±0.5 등급, 라벨 기준, 숫자 크기, 안전장치 검증이 다 없다. 영어 주제 라벨도 1,025개뿐이다.
5. **한국어 주제 모델은 정리 전 라벨로 학습돼 있다.** 주제 라벨 수정분(약 60건)과 안도형·약한 유형 564개가 아직 반영되지 않았다.
6. **사전 규칙이 커지고 있다.** 안전장치가 사전을 직접 읽어서, 사전 실수가 곧 판정 오류다. 실제로 "하루 만에"를 원인으로 오해하던 버그가 있었다. 검산(`python judge.py check`)으로 막고 있지만 시험 수가 아직 적다.
7. **`models/` 폴더가 7.2GB, 파일 114개.** 실험 모델이 섞여 있어 정리가 필요하다.
8. **뉴스 지수는 예전 모델 점수 캐시로 계산돼 있다.** 같은 사건의 여러 기사(중복)도 그대로 세고 있다.
