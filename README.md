# 오늘의 뉴스 분위기 — 경제 뉴스 제목으로 읽는 시장 분위기 지수

경제 뉴스 제목 수천 개를 작은 감성 모델로 하나하나 판정해, **오늘 뉴스가 시장을 어떻게 쓰고 있는지**를 지수로 보여 주는 웹 서비스입니다.
한국어 뉴스는 코스피, 영어 뉴스는 S&P 500과 나란히 놓고, 지수를 끌어내리거나 끌어올린 기사 묶음을 원문 링크와 함께 보여 줍니다.

- **공개 주소**: https://news-mood-index-2026-9c174.web.app (특정 시각 기준으로 고정한 시연본)
- 투자 조언이 아닙니다. 다음 날 시장을 맞히는 데 쓸 수 없습니다 (아래 '얼마나 맞나').

## 주요 기능

- **오늘 분위기**: 그날 제목 점수(−2~+2) 평균을 앞 60거래일과 견줘 '매우 부정 ~ 매우 긍정'으로 표시하고, "최근 60거래일 가운데 긍정 쪽 상위 18%"처럼 순위로도 보여 줍니다. 평소 값(평균 ± 표준편차)도 함께 적습니다.
- **실시간(잠정)**: 아직 마감 안 된 다음 거래일 몫을 10분마다 다시 셉니다. 지난 거래일들의 '같은 시각까지' 몫과 견줘 장 시작 전 기사만으로 생기는 치우침을 줄였습니다.
- **주말·휴장 분위기**: 금요일 장 마감 뒤 ~ 일요일 기사는 월요일 지수에 섞지 않고 따로 셉니다 (같은 날 상관 한국어 0.637 → 0.656).
- **기사 묶음**: 거의 같은 제목을 묶어 그날 지수를 가장 끌어내린·끌어올린 묶음 5개씩. 대표 제목은 AI(Claude Haiku)가 방향을 한 번 더 확인해 거꾸로 읽힌 것은 빼고, 시가총액 상위 업체 기사를 앞에 둡니다.
- **최근 추이·갈래별·주제 비중·섹터별**: 120거래일 추이와 종가, 시황/재료 갈래, 주제 비중, 반도체 등 고정 섹터 + 그날 제목 비중이 크게 늘어난 '특종' 섹터.
- **AI 해설**: 그날 근거 기사 묶음만 보고 쓰는 요약 (API 키가 있을 때 Claude Haiku, 없으면 시험용 문구).

## 어떻게 동작하나

```
뉴스 RSS·검색 수집 (10분마다)          collect.py, 실험/주기수집.py
  → 변환기 사전 (못 알아듣는 관용 표현을 쉬운 말로)   rewrite.py
  → 감성 모델 판정 (한국어 형태소 CMSM / 영어 낱말 CMSM, 8비트)   judge.py
  → 안전장치 (사전 규칙과 방향이 엇갈리면 중립), 전망·의견 제목 약화
  → 환율 기억 (애매한 한국어 환율 제목만, 전날까지의 원·달러와 비교)   fxmemory.py
  → 거래일 배정 (장 마감 뒤 기사는 다음 거래일, 주말·휴장 몫은 따로)   index.py
  → 하루 지수·묶음·섹터·실시간 칸 → JSON   web/build.py
  → 정적 화면 (서버·API 키 없음)   web/public/
```

- **감성 모델**: 글자 조각 + 해석 사전 특징 갈래에, 낱말(한국어는 형태소)마다 행렬을 읽는 순서대로 곱하는 갈래(CMSM)를 더한 작은 모델. 한국어 약 600만, 영어 약 5,800만 매개변수, 8비트로 줄여 CPU에서 제목당 1~3ms.
- **정답 라벨**: Claude(Opus·Haiku 등)가 붙인 투자자 관점 7단계 라벨. 라벨 기준은 `labeled/라벨기준.md`.
- **업체 규모 무게**: 시총 상위 10개 업체 제목은 하루 평균에서 ×2 (한국어로 찾고 영어로 확인).

## 얼마나 맞나

| | 한국어 (코스피) | 영어 (S&P 500) |
|---|---|---|
| 같은 날 지수 ↔ 그날 등락률 상관 | **+0.66** (927거래일) | **+0.42** (881거래일) |
| 다음 날 등락 (그날 등락을 뺀 부분상관) | 0.00 | +0.02 |
| 무작위 시험 제목 700개 (한국어) | 맞음 83.7%, 헛경보 2.1%, 방향 틀림 1개 | Haiku 검증 2,010개 7단계 68.9% |

같은 날 시장 분위기는 잘 읽지만, 다음 날을 예측하지는 못합니다. 모든 실험의 기준(결과를 보기 전에 적음)과 결과는 [`docs/실험기록.md`](docs/실험기록.md)에 있습니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `judge.py`, `rewrite.py`, `fxmemory.py`, `index.py`, `sectors.py` | 판정·변환기·환율 기억·거래일 배정·섹터 사전 |
| `collect.py`, `실험/주기수집.py` | 제목·시세 수집 (10분 주기) |
| `web/build.py`, `web/public/` | 화면 자료 만들기, 정적 웹 화면 (`web/DATA.md` = 자료 형식) |
| `web/freeze.py`, `web/DEPLOY.md` | 공개용 고정본, Firebase Hosting 배포 |
| `실험/` | 학습·평가·분석 스크립트와 결과 수치 |
| `docs/` | 실험기록, 현황과 계획, 학습 전 점검 절차 |

## 실행

```
pip install numpy kiwipiepy torch          # torch는 학습할 때만
python 실험/주기수집.py                     # 수집 → 판정 → web/public/data/latest.json (10분마다)
python -m http.server 8765 --directory web/public
python web/freeze.py && cd web && firebase deploy --only hosting   # 공개 고정본
```

모델 파일(`models/`)과 수집한 기사 제목·라벨 자료는 저장소에 넣지 않았습니다 (용량과 기사 저작권·출처 약관 때문). `실험/` 스크립트로 다시 만들 수 있습니다.

## 출처와 고지

- 뉴스: 언론사 RSS와 Google News RSS의 제목·링크만 씁니다. 본문은 화면에 싣지 않고, 묶음 대표 제목 몇 개만 원문 링크와 함께 보여 줍니다.
- 시세: 네이버 금융 공개 시세. 자세한 면책·개인정보·출처는 [`web/public/about.html`](web/public/about.html).
